## Long description

Anna VetoLayer evaluates consequential AI-agent actions before execution. It applies deterministic safety policy first, asks Anna AI only when context is genuinely needed, routes unresolved cases into structured human review, and records an integrity-tagged Decision Receipt.

Use it for production changes, permission updates, money movement, sensitive data operations, and external communications. Hard policy blocks cannot be overruled. Review approval requires evidence mapped to each outstanding requirement and a fresh policy evaluation.

Anna VetoLayer evaluates and records decisions; it does not execute the proposed third-party action.
