# Qualified-run launch checklist

Primary-function completion is a successful live Anna Policy Engine evaluation that produces and persists a non-trivial Decision Receipt. Browser preview, page opens, installs, failed tool calls, and synthetic automation are not qualified runs.

1. Invite genuine developers and operators with a specific action-evaluation use case.
2. Ask each participant to run one real or realistically scoped proposal, then collect opt-in feedback.
3. Use the in-app first-run samples only as a starting point; they still invoke the real Executa.
4. Monitor privacy-safe funnel stages: opened, started, tool_success, receipt_viewed. These events contain no action content or user identifiers.
5. Help failed users recover by restoring their Anna Agent, required grant, or storage availability; never count failed or preview runs.
6. Keep outreach truthful: do not offer deceptive incentives, create artificial accounts, or manufacture activity.
